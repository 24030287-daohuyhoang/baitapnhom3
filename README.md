# MENZONE — Website bài tập nhóm

Website giới thiệu dự án kinh doanh đồ lót nam, xây dựng bằng HTML, CSS và JavaScript thuần.

## Chạy thử trên máy
1. Giải nén thư mục.
2. Mở `index.html` bằng trình duyệt.

## Đưa website lên GitHub Pages
1. Đăng nhập GitHub và tạo repository mới, ví dụ `menzone-website`.
2. Chọn repository → **Add file → Upload files**.
3. Tải lên 3 file: `index.html`, `style.css`, `script.js` (có thể tải README lên cùng).
4. Chọn **Commit changes**.
5. Vào **Settings → Pages**.
6. Trong **Build and deployment**, chọn **Deploy from a branch**.
7. Chọn branch `main`, folder `/(root)`, rồi nhấn **Save**.
8. Chờ GitHub tạo đường dẫn website trong mục Pages.

## Cần chỉnh trước khi nộp
- Thay email `menzone@example.com` bằng email liên hệ thật của nhóm hoặc bỏ nút liên hệ.
- Cập nhật giá, hình ảnh và mô tả theo sản phẩm thực tế.
- Các con số tài chính đang là giả định lấy từ báo cáo nhóm, không phải kết quả kinh doanh thực tế.
